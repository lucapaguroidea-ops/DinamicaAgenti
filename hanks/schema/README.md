# Hankweave's hank schema, vendored

`hank.schema.json` is copied unchanged from the npm package `hankweave@0.12.0` (published
2026-09-18), `schemas/hank.schema.json`, under the Apache License 2.0 (`LICENSE.md`, from the
same package). Copyright its authors (SouthBridge AI). `tests/test_hanks.py` checks every
`hank.json` against it, so a hank that the pinned runtime would refuse fails CI here.

Upgrading the runtime means replacing this file with the new version's, re-running the tests and
recording the change in `RESEARCH_LOG.md` (R1).
